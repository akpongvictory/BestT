# BestT Project Overview


## Problem

Students have access to learning materials but lack personalized guidance.

Traditional learning platforms provide content but do not actively assist students.


## Solution

BestT is an AI learning companion that allows students to upload materials and interact with an intelligent tutor.


## Target Users

Primary:

- University students


## Core Features

1. Authentication

2. Course management

3. Document upload

4. AI tutor

5. Quiz generation

6. Progress tracking


## MVP Goal

A student should be able to:

- Register
- Create a course
- Upload notes
- Ask questions
- Generate quizzes
- Track performance
